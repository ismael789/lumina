Sugerencias populares

¿De dónde vienen los datos?

Todos los libros que ves provienen de Open Library, un proyecto del Internet Archive que cataloga cada libro jamás publicado.

  • Más de 20 millones de registros bibliográficos.
  • API gratuita y abierta — no se requiere clave de acceso.
  • Portadas, autores y ediciones vinculadas automáticamente.
  • Muchos libros están disponibles para lectura gratuita en Open Library.

Tips de búsqueda

Busca por autor

Escribe el nombre de un autor como "Gabriel García Márquez" para ver todas sus obras disponibles.

Busca por tema

Usa palabras clave como "astronomía", "recetas" o "desarrollo web" para encontrar libros de un tema específico.

Explora idiomas

Open Library tiene libros en muchos idiomas. Prueba buscando en inglés o español para más resultados.
